# Changelog / 版本记录

## 0.4.1 — 2026-11-06

### English

- Align fixed-criteria document revision and source-bound review across all four profiles. Quality and Extra Quality normally start with Terra/High; Balance and Economy prefer Terra while retaining their existing task-based effort choices.
- Keep Sol for substantive ambiguity and coupled conceptual decisions where the selected profile permits it. A reviewer role alone does not require Sol.
- Add the local bilingual revision and anonymous review comparison, with quality, time, necessary rework and token records. The comparison used High only; it does not validate lower efforts, complete profiles or Codex account allowances.
- Preserve primary models, model pools, effort ranges, the Economy/Balance/Quality/Extra Quality active child limits of 3/6/8/8, shared roles and both installation prompts. Installation preserves the user's concurrency and unrelated settings.
- Update the existing v0.4.1 release and its ZIP/SHA-256 assets in place; no new version is introduced.

### 简体中文

- 四档统一明确固定标准文稿修订与基于所给材料的审阅分工：Quality 和 Extra Quality 通常从 Terra/High 开始；Balance 和 Economy 优先 Terra，推理档位仍按原有任务标准选择。
- 在所选档位允许时，实质歧义与相互牵连的概念决策仍交给 Sol；审阅者身份本身不要求使用 Sol。
- 补充本地双语修订与匿名审阅对比，记录质量、耗时、必要返工和 token。实测只比较了 High，没有验证低推理档位、完整预设或 Codex 账户额度。
- 保留主模型、模型池、推理范围、Economy／Balance／Quality／Extra Quality 的 3／6／8／8 活跃子 agent 上限、共用角色和两种语言的安装 prompt。安装保留用户已有并发及无关设置。
- 直接更新现有 v0.4.1 发布及其 ZIP／SHA-256 附件，不增加新版本。

## 0.4.0 — 2026-11-03

- Provide four independent English profiles and eight shared roles, with bilingual documentation and subscription-based recommendations.
- Install only the selected profile. Reinstalling or switching profiles replaces the same marked `AGENTS.md` block; other `config.toml` settings are preserved.
- Keep the three installation choices: scope, profile and optional daily repository update check.
- Limit child agents working at once to 3 for Economy, 6 for Balance, and 8 for Quality and Extra Quality.

- 提供四份独立的英文配置、八个共用角色及双语文档和订阅选档建议。
- 仅安装所选配置。重装或切换档位时替换 `AGENTS.md` 中同一个标记区块；保留 `config.toml` 的其他设置。
- 保留三个安装选项：作用域、档位和可选的每日仓库更新检查。
- Economy 最多同时使用 3 个子 agent，Balance 最多 6 个，Quality 和 Extra Quality 最多 8 个。
